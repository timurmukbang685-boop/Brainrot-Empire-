# Brainrot Empire

Сайт с кейсами, апгрейдером и системой пополнения баланса Telegram Stars.

## Публикация на GitHub Pages:
1. Создайте новый репозиторий на github.com
2. Загрузите файлы из этого архива (index.html, style.css, script.js)
3. Перейдите в Settings -> Pages и выберите ветку main/master
